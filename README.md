# 式样译

面向服装加工企业的日文试样书翻译审校工作台。当前版本是可交互MVP，覆盖上传、处理进度、逐块审校、企业术语浏览和待复核HTML导出。

## 当前能力

- PDF文件选择与任务创建
- OCR、术语匹配和翻译处理进度演示
- 原文坐标标记与中日文对照审校
- 低置信度、术语冲突和待复核状态筛选
- 人工修改、确认、保留原文和术语候选操作
- 待复核/正式版交互式HTML导出
- 标准翻译服务请求与响应契约
- 为后续审批状态预留的数据类型

## 本地运行

需要Node.js 22.13或更高版本。

```bash
npm install
npm run dev
```

打开开发服务显示的本地地址即可使用。

## 构建

```bash
npm run build
```

## 翻译接口

`POST /api/translate` 使用统一的数据契约。当前提供演示适配器，后续可替换为企业已有翻译接口或其他模型服务，而不需要改变审校页面。

正式适配器需要实现以下规则：

- 固定术语优先
- 品牌、款号、色号、尺码和数值保护
- 返回逐文字块置信度
- 返回命中术语和待确认原因

## 后续升级

建议按以下顺序扩展：

1. 接入真实PDF文字提取与日文OCR
2. 接入正式翻译服务和企业术语库
3. 实现坐标级中文PDF回写
4. 增加任务持久化与文件存储
5. 增加用户、角色、分配和审批流程
6. 增加术语版本及审计记录

审批状态已经预留为：草稿、处理中、审校中、待审批、已批准、已导出。
